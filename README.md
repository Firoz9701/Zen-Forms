# 📝 Zen Forms – Opinions App

A full-stack opinions sharing application where users can post opinions and vote on them.

Built with React (frontend) and Express (backend), deployed using Netlify and Render.

---

## 🚀 Live Demo

Frontend (Netlify):  
https://zenforms.netlify.app

Backend (Render):  
https://zen-forms.onrender.com

---

## 🛠 Tech Stack

### Frontend
- React
- Context API
- Fetch API
- Vite

### Backend
- Node.js
- Express
- File System (JSON database)

### Deployment
- Netlify (Frontend)
- Render (Backend)

---

## ✨ Features

- View all opinions
- Add new opinion
- Upvote opinions
- Downvote opinions
- Form validation
- Loading simulation
- Error handling
- RESTful API

---

## 📡 API Endpoints

GET `/opinions`  
POST `/opinions`  
POST `/opinions/:id/upvote`  
POST `/opinions/:id/downvote`
